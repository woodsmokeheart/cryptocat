# Настройка админ-панели CryptoCat

## Шаг 1: Создание проекта в Supabase

1. Перейдите на [https://supabase.com](https://supabase.com)
2. Войдите в систему или создайте аккаунт
3. Создайте новый проект:
   - Нажмите "New Project"
   - Укажите название проекта (например, "cryptocat")
   - Создайте и сохраните надежный пароль для базы данных
   - Выберите регион (желательно ближайший к вашим пользователям)
   - Нажмите "Create new project"

## Шаг 2: Получение ключей API

1. После создания проекта перейдите в **Settings** → **API**
2. Скопируйте следующие значения:
   - **Project URL** (например: `https://xxxxx.supabase.co`)
   - **anon/public key** (это длинный ключ)

## Шаг 3: Настройка переменных окружения

1. Создайте файл `.env.local` в корне проекта (если его нет)
2. Добавьте следующие переменные:

```env
NEXT_PUBLIC_SUPABASE_URL=ваш_project_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=ваш_anon_key
NEXT_PUBLIC_ADMIN_EMAIL=cryptocatagency2@gmail.com
```

**Важно:** Файл `.env.local` не должен попадать в git (уже добавлен в .gitignore)

## Шаг 4: Создание пользователя-администратора

1. В панели Supabase перейдите в **Authentication** → **Users**
2. Нажмите "Add user" → "Create new user"
3. Введите данные:
   - **Email:** `cryptocatagency2@gmail.com`
   - **Password:** `Cat)159cat248crypto`
   - Снимите галочку "Auto Confirm User" если она есть
4. Нажмите "Create user"

Если у вас есть опция "Auto Confirm User", убедитесь что она отключена, либо после создания пользователя:
- Перейдите к созданному пользователю
- Нажмите на три точки (⋮) → "Confirm user"

## Шаг 5: Настройка Email провайдера (опционально)

По умолчанию Supabase использует свой встроенный SMTP сервис для тестирования. Для продакшена рекомендуется настроить собственный:

1. Перейдите в **Settings** → **Auth** → **Email**
2. Настройте SMTP сервер (можно использовать Gmail, SendGrid, и т.д.)

## Шаг 6: Запуск приложения

```bash
npm run dev
```

Теперь админ-панель доступна по адресу: [http://localhost:3000/admin](http://localhost:3000/admin)

## Настройка регистрации (отключение публичной регистрации)

Чтобы никто кроме вас не мог зарегистрироваться:

1. В Supabase перейдите в **Authentication** → **Settings** → **Auth Providers**
2. Найдите "Enable Email Signup"
3. **Отключите** эту опцию

Теперь новые пользователи не смогут зарегистрироваться через форму, только через панель администратора Supabase.

## Устранение неполадок

### Ошибка "Invalid login credentials"
- Проверьте правильность email и пароля
- Убедитесь что пользователь подтвержден в Supabase (confirmed)

### Редирект на /admin/login после успешного входа
- Проверьте что переменные окружения правильно настроены
- Перезапустите dev сервер после изменения `.env.local`

### Ошибки middleware
- Убедитесь что файл `middleware.ts` находится в корне проекта
- Проверьте правильность путей импортов
