# Настройка системы управления слайдами

## 🎯 Описание

Система управления слайдами главной страницы позволяет администратору:
- Создавать, редактировать и удалять слайды
- Загружать фоновые изображения (до 5MB)
- Настраивать порядок отображения слайдов
- Включать/выключать слайды
- Добавлять ссылки на статьи

## 🚀 Использование

### 1. Доступ к управлению слайдами

1. Войдите в админ-панель: `/admin`
2. Нажмите на карточку "Слайды"
3. Или перейдите напрямую: `/admin/slides`

### 2. Создание слайда

1. Нажмите "Создать слайд"
2. Заполните поля:
   - **Заголовок** - маленький заголовок сверху (например: "Команда")
   - **Основной заголовок** - основной текст (например: "Спокойствие - это")
   - **Акцентный заголовок** - выделенная часть (например: "решение")
   - **Описание** - основной текст описания
   - **Акцентное описание** - выделенная часть описания
   - **Ссылка** (необязательно) - URL для перехода
   - **Текст ссылки** (необязательно) - текст ссылки
   - **Порядок** - порядок отображения (0, 1, 2...)
3. Загрузите фоновое изображение (до 5MB)
4. Нажмите "Создать слайд"

### 3. Редактирование слайда

1. В списке слайдов нажмите кнопку "Редактировать" (иконка карандаша)
2. Внесите изменения
3. Нажмите "Обновить слайд"

### 4. Управление слайдами

- **Перемещение** - используйте стрелки вверх/вниз для изменения порядка
- **Включение/выключение** - используйте кнопку глаза для показа/скрытия
- **Удаление** - используйте кнопку корзины (необратимо!)

## 🔧 Технические детали

### Загрузка изображений
- Максимальный размер: 5MB
- Поддерживаемые форматы: JPG, PNG, WebP
- Загрузка через API `/api/upload`
- Сохранение в папку `slides/`

### Кэширование
- Слайды загружаются на клиенте
- Fallback слайды при ошибке загрузки
- Автоматическое обновление при изменениях

### Безопасность
- RLS (Row Level Security) включен
- Только админ может управлять слайдами
- Публичное чтение только активных слайдов

## 🐛 Устранение неполадок

### Слайды не загружаются
1. Проверьте, что таблица `slides` создана
2. Убедитесь, что RLS политики настроены
3. Проверьте консоль браузера на ошибки

### Изображения не отображаются
1. Проверьте, что изображения загружены в Supabase Storage
2. Убедитесь, что URL изображений корректные
3. Проверьте права доступа к Storage

### Ошибки при создании/редактировании
1. Убедитесь, что вы вошли в систему как админ
2. Проверьте, что все обязательные поля заполнены
3. Убедитесь, что размер изображения не превышает 5MB
