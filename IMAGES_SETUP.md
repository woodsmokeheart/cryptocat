# Настройка работы с изображениями в постах

## 📋 Обзор

Система позволяет загружать изображения в посты и использовать одно из них как обложку для карточки поста.

## 🚀 Шаг 1: Обновление базы данных

### 1.1 Добавление поля cover_image

Выполните SQL из файла `supabase-update-posts.sql` в Supabase SQL Editor:

1. Откройте [Supabase Dashboard](https://supabase.com/dashboard)
2. Выберите ваш проект
3. Перейдите в **SQL Editor** → **New Query**
4. Скопируйте содержимое `supabase-update-posts.sql`
5. Нажмите **Run**

### 1.2 Настройка Storage

Выполните SQL из файла `supabase-storage-setup.sql`:

1. В том же SQL Editor создайте новый запрос
2. Скопируйте содержимое `supabase-storage-setup.sql`
3. Нажмите **Run**

Это создаст:
- Bucket `post-images` для хранения изображений
- RLS политики для безопасности
- Публичный доступ к изображениям

## 📸 Шаг 2: Загрузка изображений

### Как загрузить изображение в пост:

1. **Откройте редактор поста** (создание или редактирование)
2. **Поместите курсор** в нужное место в тексте
3. **Нажмите кнопку "Изображение"** в панели редактора
4. **Выберите файл** с вашего компьютера
5. **Дождитесь загрузки** - изображение автоматически вставится в текст

### Ограничения:

✅ **Максимальный размер**: 5 MB  
✅ **Форматы**: JPEG, PNG, WebP, GIF  
❌ Файлы больше 5 MB будут отклонены с предупреждением  

## 🎨 Шаг 3: Выбор обложки поста

### Автоматическое отображение:

После добавления изображений в пост, под редактором появится секция **"Обложка поста"**.

### Как выбрать обложку:

1. **Добавьте изображения** в содержимое поста
2. **Секция "Обложка поста"** появится автоматически
3. **Нажмите на изображение**, которое хотите использовать как обложку
4. **Или выберите "Без обложки"** если не хотите обложку

### Где отображается обложка:

- ✅ В карточке поста на странице списка постов
- ✅ Сверху карточки, над заголовком
- ✅ С эффектом увеличения при hover

## 🔐 Безопасность

### RLS политики Supabase Storage:

- ✅ **Загрузка**: только авторизованные пользователи
- ✅ **Обновление**: только авторизованные пользователи
- ✅ **Удаление**: только авторизованные пользователи
- ✅ **Просмотр**: публичный доступ (для отображения на сайте)

### Валидация:

- ✅ **Размер файла**: проверка на клиенте (5 MB)
- ✅ **Тип файла**: проверка формата (JPEG, PNG, WebP, GIF)
- ✅ **Сообщения об ошибках**: понятные уведомления пользователю

## 📁 Структура Storage

```
post-images/
├── posts/
│   ├── 1234567890-abc123.jpg
│   ├── 1234567891-def456.png
│   └── ...
```

### Формат имён файлов:

`{timestamp}-{random}.{ext}`

Например: `1704067200000-9xy4k2.jpg`

## 🎯 Использование

### 1. Создание поста с изображением

```
1. Перейдите на /admin/posts/new
2. Заполните заголовок и описание
3. В редакторе нажмите "Изображение"
4. Загрузите файл (до 5 MB)
5. Изображение вставится в текст
6. Выберите его как обложку (опционально)
7. Сохраните пост
```

### 2. Редактирование изображений

```
1. Откройте пост для редактирования
2. Добавьте новые изображения через кнопку "Изображение"
3. Удалите ненужные изображения (просто удалите из текста)
4. Измените обложку (выберите другое изображение)
5. Сохраните изменения
```

## 🖼️ Технические детали

### Компоненты:

- **ImageUpload** - компонент загрузки изображений
- **extractImagesFromContent()** - извлечение URL изображений из HTML
- **uploadImage()** - загрузка в Supabase Storage
- **validateImageSize()** - валидация размера
- **validateImageType()** - валидация типа

### API:

Изображения хранятся в Supabase Storage bucket `post-images`.

Публичный URL формируется автоматически:
```
https://[your-project].supabase.co/storage/v1/object/public/post-images/posts/[filename]
```

### Обложка поста:

Поле `cover_image` в таблице `posts` хранит URL выбранной обложки.

Если обложка не выбрана: `cover_image = null`
