# Система управления постами

## 📋 Обзор

Полнофункциональная система управления постами с богатым текстовым редактором TipTap, пагинацией и полным CRUD функционалом.

## ✨ Возможности

- ✅ **Создание постов** с TipTap редактором
- ✅ **Редактирование постов** 
- ✅ **Удаление постов** с подтверждением
- ✅ **Просмотр постов** в читаемом формате
- ✅ **Список постов** с пагинацией (9 постов на страницу)
- ✅ **Статусы постов**: Опубликован / Черновик
- ✅ **Краткое описание** для карточек постов

## 🎨 TipTap редактор

### Возможности форматирования:

**Текст:**
- Жирный (Ctrl+B)
- Курсив (Ctrl+I)
- Подчёркнутый (Ctrl+U)
- Зачёркнутый

**Заголовки:**
- H1, H2, H3, H4

**Списки:**
- Маркированный список
- Нумерованный список
- Цитаты

**Выравнивание:**
- По левому краю
- По центру
- По правому краю

**Дополнительно:**
- Ссылки
- Изображения (по URL)
- Отмена/Повтор (Ctrl+Z / Ctrl+Shift+Z)

## 🗄️ База данных

### Таблица `posts`

| Поле | Тип | Описание |
|------|-----|----------|
| id | UUID | Уникальный ID поста |
| title | TEXT | Заголовок поста |
| content | TEXT | HTML контент поста |
| excerpt | TEXT | Краткое описание |
| published | BOOLEAN | Статус публикации |
| created_at | TIMESTAMP | Дата создания |
| updated_at | TIMESTAMP | Дата обновления |
| author_id | UUID | ID автора (FK на auth.users) |

### Индексы
- `idx_posts_author_id` - по автору
- `idx_posts_created_at` - по дате создания (DESC)
- `idx_posts_published` - по статусу публикации

### RLS (Row Level Security)
- Админ может выполнять все операции со своими постами
- Автоматическое обновление `updated_at` при изменении

## 🚀 Использование

### 1. Настройка базы данных

Выполните SQL из файла `supabase-schema.sql` в Supabase SQL Editor:

```bash
# Откройте Supabase Dashboard → SQL Editor → New Query
# Скопируйте содержимое supabase-schema.sql
# Нажмите Run
```

### 2. Создание поста

1. Перейдите в админ-панель: `/admin`
2. Нажмите на карточку "Посты" или `/admin/posts`
3. Нажмите "+ Создать пост"
4. Заполните:
   - **Заголовок** (обязательно)
   - **Краткое описание** (опционально, для карточки)
   - **Содержимое** (обязательно, используйте редактор)
   - **Опубликовать** (чекбокс)
5. Нажмите "Создать пост"

### 3. Редактирование поста

1. Откройте список постов `/admin/posts`
2. Найдите нужный пост
3. Нажмите "Редактировать"
4. Внесите изменения
5. Нажмите "Сохранить изменения"

### 4. Просмотр поста

1. В списке постов нажмите "Просмотр"
2. Или перейдите на `/admin/posts/[id]`
3. Здесь можно:
   - Прочитать пост
   - Редактировать (кнопка ✏️)
   - Удалить (кнопка 🗑)

### 5. Удаление поста

1. Откройте пост для просмотра
2. Нажмите кнопку "🗑 Удалить"
3. Подтвердите удаление
4. Пост будет удалён навсегда

## 🎯 Статусы постов

### Опубликован
- Зелёный бадж "Опубликован"
- Пост готов к показу (если будет публичная часть)

### Черновик
- Серый бадж "Черновик"
- Пост не опубликован, виден только в админке
